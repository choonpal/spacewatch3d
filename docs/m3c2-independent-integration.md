# M3C2 독립 탐지와 변화 종류의 통합

2026-10-15. 실제 `Rescan scene_e_0 → scene_e_2`. 기존 12개 변화 항목은 보존하고 별도 출처로 표시한다. 화면의 새 출처 이름은 **의심 구역**이다. 생성 파일과 원본 RGB-D는 Git에 포함하지 않는다. 현재 서버는 노이즈 억제를 적용한 `outputs/m3c2-noise-screen-v2-20261015`를 사용한다.

## 라벨을 사용하는 범위

새 탐지·표면 대응·종류 판단에는 semantic class, instance ID, 기존 추가/소실/이동 type을 넣지 않는다. 기존 결과에서 읽는 정보는 중복 제외를 위한 **전후 영역 상자와 이미 표시한 프레임 ID**다. 이는 독립 후보를 발견한 뒤 중복을 제거하는 조건이며 새 종류의 근거가 아니다. 기존 metadata의 객체 ID/type을 바꿔도 제외 상자와 프레임 ID가 같으면 결과에 영향을 주지 않는 테스트를 포함한다.

카메라 복원은 원본 RGB의 optical flow, 메쉬 ray intersection의 3D 점, PnP reprojection 및 원본 깊이의 ICP를 사용한다. 객체 라벨은 사용하지 않는다. 학습 모델을 사용하지 않으며, 복원한 카메라는 추정값이다.

## 입력과 실행

기존 기하 비교의 `comparison.json`, `core-fields.npz`, `0/1-comparison.bin`, 공통 좌표의 캐시 메쉬, 원본 `.h264`/`.depth`가 필요하다. 카메라 앵커는 기존 label-free localization 결과의 RGB 확인 프레임이다. `tools/mesh-comparison-requirements.txt`의 과학 계산 환경을 쓴다. 원본 depth decoder는 이전 작업에서 빌드한 `third_party/rescan-depth/decode.exe`다.

```powershell
python tools/recover_m3c2_frames.py `
  --data data/rescan/scene_e_0-2 `
  --review-dir outputs/rescan-three-changes `
  --output outputs/m3c2-frame-recovery-20261015
python tools/build_m3c2_independent.py `
  --comparison-dir outputs/mesh-comparison-final2-20261015 `
  --review-dir outputs/rescan-three-changes `
  --frames-dir outputs/m3c2-frame-recovery-20261015 `
  --output outputs/m3c2-noise-screen-v2-20261015
python apps/autotour360/server.py --port 8768 `
  --rescan-dir outputs/rescan-three-changes `
  --mesh-comparison-dir outputs/mesh-comparison-final2-20261015 `
  --independent-dir outputs/m3c2-noise-screen-v2-20261015
```

명령은 저장소 루트 기준이다. 출력 폴더가 이미 차 있으면 새 경로를 쓴다. 입력·이전 결과는 보존한다. 서버 URL은 `http://127.0.0.1:8768/mesh-comparison.html`이다.

## 통합 판단 순서

1. 기존 label-free M3C2의 변화/의심 기준을 넘은 표면 코어를 가져온다. 여기서 `core-fields.npz`의 `classes`는 **M3C2 임계값 분류 0–3**이며 Rescan 객체 클래스가 아니다. 반대 메쉬와 4.5cm 이상 차이가 있는 표면을 남긴다.
2. 기존 전후 상자를 15cm 확장해 제외한다. 표면 코어를 13cm 그리드에서 연결하고 넓은 부분은 1.1m 공간 타일로 나눈다. 객체 분할이 아니라 기하 표면 구역이다. 최소 코어는 9개다. 상자가 기존 영역과 겹치면 제외한다.
3. 원본 depth에서 해당 위치의 상태를 구한다. 실제 반환 깊이가 query와 가까우면 occupied, 충분히 뒤에 있으면 free, 앞에 있으면 occluded다. 유효하지 않은 깊이·화면 밖·깊이 경계는 unknown이다. **메쉬 구멍을 free로 처리하지 않는다.**
4. 자기 시점에서 2개 이상 깊이 관측으로 지지된 표본이 40% 이상, 반대 시점에서 2개 이상 free로 지지된 표본이 55% 이상이고 free 관측 카메라 간격이 15cm 이상인지를 확인한다. M3C2 명확한 변화 표본 비율 55% 이상, 반대 표면 거리 중앙값 8cm 이상도 필요하다. 이 수치는 수동으로 정한 데모 규칙이며 보정된 확률이 아니다.
5. 이전에만 지지되는 표면과 이후에만 지지되는 표면을 기하학적으로 대응시킨다. 다중 초기 강체 ICP의 양방향 겹침 >70%, 거리 중앙값 <3.5cm, 상호 최선 대응 및 다른 대응과 비용 차이 >0.25일 때 이동으로 추정한다. 평면이나 반복적인 비슷한 표면의 모호한 대응은 이동으로 강제하지 않는다.
6. 뚜렷한 존재 차이가 있고 이동 대응이 없으면 이전 쪽 표면은 소실, 이후 쪽 표면은 추가로 추정한다. 관측 부족·가림·약한 M3C2 근거·여러 대응·약한 사진 위치 연결은 **의심 구역**으로 남긴다. 이는 whole-object identity에 대한 보증이 아니라 surface-region change의 조건부 추정이다.

Occupied tolerance는 `0.065 + 0.015*z`m, free margin은 `0.14 + 0.015*z`m이다. 5개 인접 depth sample이 모두 유효하고 깊이 경계가 아닌 경우만 쓴다. 후보 생성/분류 규칙과 생략 범위는 산출 `changes.json`에도 저장한다. 카메라·재구성 오차가 보정된 통계 모델이나 공인된 change classifier를 구현했다고 주장하지 않는다.

## 중복 없는 원본 사진 연결

기존 12개 항목에서 사용한 프레임 ID 45개를 제외한다. 기존 RGB 앵커 주변의 서로 다른 원본 프레임 26개를 추출했고 22개에서 temporal RGB/mesh PnP gate를 통과했다. 새 RGB 카메라와 depth 카메라는 별도로 복원한다. 전후 모두 같은 3D 구역을 투영할 수 있는 원본을 선택하고 추정 상자를 표시한다. 약한 depth-only 위치 후보에는 상자를 표시하지 않는다.

AI 생성·합성 없이 원본 영상의 정지 프레임을 648×484 JPEG로 축소해 표시한다. UI는 키프레임 넘기기·전체 프레임 확대를 제공한다. 새로 표시한 프레임은 기존 항목의 45개 프레임과 ID 중복이 없다. 서로 다른 새 구역끼리는 같은 원본 프레임을 사용할 수 있다.

- 기하 패치: 이전 8개 / 이후 5개. 공간 중복 제거 후 후보는 8개다.
- 전후 원본을 모두 연결한 구역: **2개**, 표시한 서로 다른 원본 프레임 6개.
- 독립 통합 판단: **추가 0 / 소실 0 / 이동 0 / 의심 구역 2**.
- 기존 영역과 겹치는 코어: **0**. 기존 표시 프레임과 ID 중복: **0**.
- 전후 원본 후보가 부족해 화면 목록에 넣지 않은 6개 후보도 `unlinked_candidates`로 기록한다.

두 표시 구역의 검출 표본 거리 중앙값은 약 **5.4cm**다. 구역 전체에서 명확한 M3C2 근거가 유지되지 않고 raw depth 관측도 종류를 뒷받침하지 못해 의심으로 보류했다. 기존 2/1/9 라벨로 새 항목의 종류를 채우지 않았다. 이 결과를 독립 추가/소실/이동 검출 성공이라고 보고하지 않는다.

## 노이즈 억제 계산 변경

`tools/mesh_change_noise.py`가 명목 M3C2 후보 이후, 변화 종류 판단 이전에 작동한다. 메쉬 표본은 같은 재구성 표면을 촘촘히 뽑은 것이므로 표본 개수로 요철 오차가 계속 작아진다고 취급하지 않는다. 아래 계산은 직접 구현한 보수적인 후보 억제 규칙이며, 보정된 확률 또는 M3C2-EP 구현은 아니다.

- 반경 **8·16·28cm**의 법선 방향 이웃에서 가장 가까운 지지된 표면층을 비교한다. 분리된 바닥/테이블 등의 층을 한 평균으로 섞지 않는다. 각 층에 최소 표본 6개가 필요하다.
- 표면 위치는 중앙값, 표면 요철은 `max(1.4826*MAD, (P90-P10)/2.563)`로 구한다.
- 오차 범위는 `1.96*sqrt(spread_before² + spread_after² + 2*0.02²)`m다. 각 맵의 정합 오차를 2cm, 두 오차는 독립이라고 가정한다. 실제 공분산을 추정한 값은 아니다. **메쉬 표본 수로 나누지 않는다.**
- 거리 6cm 이상이면서 오차 범위를 **같은 방향으로 2개 이상 크기에서** 넘는 표본을 남긴다. 그런 표본이 원래 후보 패치의 **55% 이상**이어야 한다.
- 후보 표면은 자기 시점의 원본 depth에서 2회 이상 지지되는 표본이 **40% 이상**이어야 한다. 자기 표면부터 확인되지 않는 재구성 조각을 단순히 '의심'으로 승격하지 않는다. 자기 표면이 확인됐으나 반대 시점에서 가려진 경우는 기존 종류 판단에서 미정으로 남길 수 있다.

이 규칙에는 floor height, instance/semantic labels, 사람이 지적한 바닥 좌표가 들어가지 않는다. 기존 라벨 결과에서 쓰는 것은 여전히 중복 제외 상자와 프레임 ID뿐이다. 후보 억제의 원인과 공간 범위는 `suppressed_regions`에, 크기별 거리·오차 범위는 비공개 로컬 `candidate-fields.npz`에 보존한다.

## 노이즈 억제 후 실제 결과

같은 입력 메쉬 해시·동일한 M3C2 코어·동일한 복원 카메라를 사용했다. 초기 출력과 중간 실험 출력은 덮어쓰지 않았다.

| 사용자가 무변화로 지적한 바닥 | 기존 거리 중앙값 | 새 오차 범위 중앙값 | 새 크기 일관성 기준 통과 표본 | 결과 |
|---|---:|---:|---:|---|
| 초기 구역 1001, 코어 79개 | 5.38cm | 5.62cm | 29.1% | 노이즈 범위로 제외 |
| 초기 구역 1002, 코어 49개 | 5.40cm | 5.72cm | 16.3% | 노이즈 범위로 제외 |

위 표는 여러 값의 중앙값을 요약한 것이며 개별 표본에 적용한 판정식을 대신하지 않는다. 이 두 구역의 코어는 새 `candidate_mask`와 공개 footprint에 남지 않는다. 추가로 원본 깊이가 지지하는 비율이 5%뿐인 인접 표면도 제외됐다.

- 원래 기존 영역 밖 후보 코어: 1,398개. 다중 크기 기준을 넘는 코어는 735개다.
- 패치 억제: 11개. 그중 4개는 요철·오차/크기 일관성 기준 미달, 7개는 자기 시점 원본 깊이 지지 부족이다. **11개 전부를 검증된 오탐이라고 주장하지 않는다.**
- 기하와 자기 depth 지지 기준을 통과한 후보: 1개, 코어 10개. 전후 사진 연결이 부족해 `unlinked_candidates`에 남긴다.
- 사진까지 연결한 새 결과: 추가 0 / 소실 0 / 이동 0 / 유형 미정 0.
- 기존 라벨 기반 비교 12개는 새 탐지 성능 수치에 포함하지 않고 별도로 유지한다.

빈 새 결과도 정상 산출한다. 화면은 기존 라벨 결과로 자동 전환하지 않는다. 새 구역이 없다는 설명, 억제 개수, 사진 미연결 개수를 보이고, 원본 사진은 **공간 참고**로 명시해 표시한다. 이 사진에는 검출 상자나 실제 변화 주장을 붙이지 않는다.

분석 검사는 노이즈가 있는 미변화 평면/벽과 밀도 증가에 대한 억제, 실제 18cm 표면 차이 유지, 바닥 위 24cm 표면의 추가/소실 유지, 원본 깊이 지지가 없는 표면 제외를 포함한다. 기존 강체 이동·모호한 대응·가림 처리 검사도 통과했다. 이는 알려진 두 음성 사례와 합성 양성 사례의 회귀 확인이며 실내 데이터셋 전반의 precision/recall 평가가 아니다. 6cm 미만 변화, 관측 부족의 실제 변화는 놓칠 수 있고 큰 체계적 정합 오차는 남을 수 있다.

## 화면과 산출물

기본 상위 버튼은 **의심 구역**이며 '기존 Rescan 비교' 버튼으로 기존 12개 항목을 볼 수 있다. 하위 필터는 **전체·추가·소실·이동**이다. `suspected`는 내부 데이터 형식으로 유지하지만 화면에서 별도 의심 구역 유형 버튼을 만들지 않는다. 종류를 결정할 근거가 부족한 항목은 전체 목록에서 **유형 미정·변화 근거 부족**으로 표시한다. 바닥 두 곳을 임의로 추가·소실·이동으로 다시 라벨링하지 않았다.

노이즈 억제 이전의 5.4cm 표시는 명목 M3C2 거리이며 변화 확률이 아니다. 현재 후보가 남으면 새 다중 크기 거리·오차 범위·일관성 표본 비율을 표시한다. '원시 표면 차이 · 노이즈 포함' 모드는 기존 명목 M3C2/GLS 측정값을 보존한 참고 모드이며, 억제 후 후보 목록과 구분한다.

출처별 유형 개수와 보류 이유, 전후 사진을 표시한다. 구역의 지도 색칠은 상자 전체가 아니라 실제 검출 코어에 대응하는 `0/1-region-ids.bin` footprint에만 적용한다. M3C2가 후보·통합 판단의 출처이고 GLS는 같은 위치의 참고 비교다. 원래 전체 표면 차이 모드도 유지한다.

새 라우트 `/m3c2-independent/`는 결과 JSON, 두 footprint binary, 원본 JPEG만 공개한다. raw depth·중간 npz·임의 경로는 제공하지 않는다. `candidate-fields.npz`와 입력 해시·임계값·관측 근거가 있는 JSON은 로컬 재현용으로 보존한다.

## 확인

원본 depth의 free/occupied/occluded/unknown 구분, 관측 없이 소실로 판단하지 않기, 반복 형상의 모호한 이동 보류, 고유한 3D 표면의 강체 이동, 추가/소실/이동/의심 통합 분기, 객체 라벨 변경에 대한 제외 조건 불변성을 unit test로 확인한다. UI 테스트는 출처 분리·기존 프레임 중복 거부·잘못된 메쉬 거부·정확한 footprint 집계를 확인한다. 이는 동작 확인이며 실제 검출 정확도 benchmark가 아니다.
