SPACEWATCH변화 후보 비교실행 환경 확인 중

SEGMENTED MESH + ORIGINAL RGB

전후 촬영을 비교합니다

메쉬·RGB·포인트클라우드를 정합하고, SimSaC가 찾은 변화 후보를 원본 영상에서 비교합니다.

서버에 있는 촬영 입력

전후 촬영을 선택하면 자동으로 변화비교를 시작합니다. 기존 영상과 메쉬·객체 후보·점군·카메라를 함께 불러옵니다.

입력 파일 구성

ZIP 최상위의 manifest.json에 전후 파일과 카메라 정보를 연결합니다. 메쉬 NPZ에는 vertices / faces / face_instance_id를 넣습니다. RGB와 메쉬를 같은 위치에서 비교할 수 있도록 프레임별 카메라 포즈가 필요합니다. 일반 사진은 카메라 내부 파라미터 K도 포함합니다.

전후 포인트클라우드를 함께 넣으면 정합 잔차와 가림·빈자리 관측을 독립적으로 검증합니다. 메쉬에서 빠진 촬영자는 원본 RGB의 사람 마스크로 제외합니다. 서버의 사람 검출 모델을 쓰거나 이미지와 같은 크기의 person_mask를 제공합니다.

입력 JSON 예시 내려받기
manifest.json
before/mesh.npz
before/001.jpg, 002.jpg …
before/points.npz
after/mesh.npz
after/001.jpg, 002.jpg …
after/points.npz

첫 입력은 새로 분석합니다. 입력·카메라·설정·모델이 같으면 완료된 분석을 다시 사용합니다.

  1. 입력 확인
  2. 메쉬 정합
  3. 촬영자 제외 · SimSaC
  4. 후보 근거 정리
  5. 전후 결과 표시
