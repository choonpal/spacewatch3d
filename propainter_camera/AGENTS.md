# GPU 서버 및 현재 처리 방식

- 사용자 지시(2026-10-27): SSH 서버는 `root@10.132.1.13`, 포트 `4444`를 사용한다. 이전 IP 주소를 사용하지 않는다.
- 모든 모델 추론 및 GPU 연산은 이 서버에서 실행한다. 로컬 또는 Colab으로 대체하지 않는다.
- 실행 직전 GPU 사용 현황을 확인하고, 대화창 하나당 여유 GPU를 동시에 최대 1개만 사용한다. 다른 작업을 중지하거나 점유하지 않는다.
- 비밀번호는 파일, 코드 또는 로그에 저장하지 않는다.
- 사용자 지시(2026-10-28): PanoGRF를 사용하지 않고 실제 촬영 카메라 프레임에서 ProPainter 결과를 360도 이미지로 복원한다.
- 이 폴더는 현재 실행 코드·설정·결과의 로컬 사본이다. 서버 실행 폴더는 `/workspace/propainter_camera_20261028`이다.
- 키프레임은 `config.json`의 `selected_camera_ids`로 지정한다. PanoGRF 추론 단계를 다시 연결하지 않는다.
- `results/`와 `migration/`은 결과 및 이력이다. 원본 영상과 모델 가중치는 서버의 설정 경로에 보관되어 있다.
