# 객체 주변 기준 표면의 방향 확장 · 2026-10-19

현재 변화 투어는 사용자 요청에 따라 기존 이동 9·추가 2·소실 1 분류로 복원했다. 아래는 복원 전 실험 기록이며 현재 화면의 분류·사용법을 뜻하지 않는다. 계산 코드와 산출물은 보존했다.

Rescan `scene_e_0 → scene_e_2`의 기존 12개 항목과 전후 원본 키프레임을 유지하고, 주변 정합 오차를 추정할 기준 표면의 탐색 범위를 넓혔다. 첫 실행의 바닥·서로 평행한 벽만으로 빠졌던 방향을 보완한다. 기준 표면 선택·국소 정합 오차 계산·반경 선택에는 변화 정답, 객체 클래스, 인스턴스 ID를 사용하지 않는다. 기존 객체 후보·대응·변위 추정은 현재 뷰어 입력 그대로이므로 전체 객체 탐지가 새로 라벨 없이 수행됐다는 의미는 아니다.

## 방법

`tools/stable_surface_patches.py`는 원본 점 관측으로 지지되는 메쉬 XYZ와 법선만 받는다. 35cm 공간 셀에서 방향 제한 없이 평면 조각을 찾고, 전후 법선·형상 두께·서로 대응하는 표본 비율을 확인한다. 표면의 법선 방향 오프셋을 0으로 강제하지 않아 공통 정합 어긋남을 다음 단계에서 추정할 수 있다. 큰 정합 오차나 큰 형상 변화로 대응이 12cm를 넘는 면은 기준 후보에서 빠진다.

객체별로 이전·이후 위치의 경계 상자와 15cm 여유 공간을 모두 제외하고, 주변 1 / 1.5 / 2.5m에서 기준 표면을 고른다. 기존 구조면과 다른 법선 방향은 최소 3패치, 학습용 3공간 셀·별도 확인용 2셀, 50cm 이상의 패치 분포가 있어야 포함한다. 평행에 가까운 법선은 12° 이내에서 하나로 묶어 거친 면의 미세한 법선 흔들림으로 세 번째 방향을 만들지 않는다.

공간 셀 단위로 분리한 별도 표면에서 새 방향의 잔차를 확인한다. 확인 잔차 P95가 학습 잔차 P95의 2배와 2.5cm 중 큰 값 이하여야 통과한다. 실패한 새 방향은 제거하고 한 번 다시 추정한다. 전체 정합 보정이 기존 허용 범위 15cm·5°를 넘으면 기존 구조면으로 되돌린다. 세 방향이 모두 확인되는 가장 작은 반경을 선택하고, 그런 반경이 없으면 확인 방향이 가장 많은 반경 중 가장 작은 것을 고른다. 객체 판정 결과를 보고 반경을 고르지 않는다.

이동 판정의 기존 `CONFIG`는 수정하지 않았다. 8cm 최소 이동량, 15° 최소 회전량, 객체 대응 품질·모호성 조건, 공간 블록 재표본화, 표면 잔차로 구하는 경험적 오차 범위는 그대로다. 새 기준 표면과 확인 방향·기하 조건이 달라져 객체별 오차 범위는 다시 계산된다.

## 실제 결과

전체에서 140개의 추가 공통 표면 후보, 7,517쌍을 찾았다. 이는 후보 총수이며 각 객체에서 모두 쓰는 것은 아니다. 기존 구조면과 중복되는 표본, 대상 객체 내부, 지지·확인 조건을 통과하지 못한 새 방향을 제외했다.

이전 보류 5개는 다음과 같이 달라졌다. 단위는 cm다. `잔여 변위`는 확인 가능한 방향에서 주변 정합 영향을 보정한 값이며, 이전 실행과 확인 방향 수가 달라지면 비교 대상 방향도 달라진다.

| 기존 객체 | 확인 방향 이전→현재 | 현재 잔여 변위 | 현재 판정 기준 | 현재 판정·이유 | 추가 패치 / 반경 |
|---|---|---:|---:|---|---|
| 기타 가구 #13 | 2→3 | 24.8 | 21.5 | 이동 근거: 기준 초과 | 27 / 1.5m |
| 의자 #19 | 2→3 | 52.3 | 13.7 | 보류: 기존 전후 객체 대응이 모호함 | 25 / 1.5m |
| 의자 #20 | 2→3 | 17.8 | 20.7 | 오차 범위 안: 이동으로 확정할 근거 부족 | 56 / 2.5m |
| 의자 #21 | 2→3 | 44.5 | 13.4 | 보류: 기존 전후 객체 대응이 모호함 | 12 / 1.0m |
| 소파 #25 | 1→1 | 0.2* | 15.5 | 보류: 수평 방향의 정합 영향 미확인 | 18 / 2.5m |

`*` 소파의 0.2cm는 한 방향 성분이다. 관측된 전체 변위 19.4cm를 설명했다고 해석할 수 없다. 추가 표면 18개도 기존 방향을 보강할 뿐 새 독립 방향을 제공하지 못했다.

의자 #20은 관측 전체 변위 22.3cm, 주변 정합 영향 4.6cm, 보정 후 17.8cm다. 오차 범위 20.7cm가 넓기 때문에 비이동을 확정한 것이 아니다. 그 객체의 전후 위치 주변 2.5m를 합친 기준 영역을 사용하며, 작은 한 벽 조각만으로 오차를 추정한 결과가 아니다.

전체 12개는 첫 실행 `이동 근거 4 / 오차 범위 0 / 보류 5 / 추가·소실 3`에서 현재 `5 / 1 / 3 / 3`으로 바뀌었다. 추가·소실 3개와 기존 객체 대응은 유지했다. 보류 감소를 탐지 정확도 상승이나 정답 검증으로 표현하지 않는다.

## 뷰어

`http://127.0.0.1:8768/?mode=changes&references=expanded`에서 이전 보류 5개와 첫 항목을 선택한다. 각 객체의 확장 전후 판정·확인 방향·비교 가능 변위·기준을 나란히 표시한다. 청록 테두리는 실제로 해당 객체의 주변 오차 추정에 포함한 추가 표면의 위치다. 많은 경우 최대 32패치를 대표 표시하며, 가려진 표면도 비교용으로 투영한다. 현재 사진에 보이는 객체의 분할 마스크가 아니다. 기존 전후 원본 사진·객체 사진 반투명 겹침·지점 이동도 유지한다.

기본 서버와 이 PC의 `start-autotour360.cmd`는 새 보고서를 사용한다. 기존 보고서는 별도 경로에 보존했다.

## 실행과 산출물

과학 계산 환경에 numpy, scipy, Open3D, plyfile이 필요하다. 저장소 루트에서 새 빈 출력 폴더를 지정한다.

```bash
python tools/build_local_motion_assessment.py \
  --review-dir outputs/rescan-three-changes \
  --structural-dir outputs/structural-reference-rescan-v5-20261016 \
  --output outputs/local-motion-expanded-20261019/run-v1 \
  --expanded-references \
  --baseline-assessment outputs/local-motion-assessment-20261019/run-v3/motion-assessment.json
```

이번 실행의 `protocol.json`은 실행 전에 계산 조건을 저장했다. `patch-candidates.json`, `background-correspondences.npz`, `support-audit.json`으로 후보·대응·객체별 사용 표본을 추적할 수 있다. 공개 `motion-assessment.json`에는 현재 결과와 이전 보고서의 대응 항목, 입력 SHA256, 방향별 지지·별도 구역 확인 결과, 표시할 표면 좌표를 저장했다. 이전 보고서는 새 탐색·계산·판정이 끝난 후 비교용으로만 읽는다.

```bash
python apps/autotour360/server.py --port 8768 \
  --rescan-dir outputs/rescan-three-changes \
  --motion-assessment outputs/local-motion-expanded-20261019/run-v1/motion-assessment.json
```

원본 `changes.json` SHA256는 `288354abf7bbb46b232289ab15fce3f41a3716d62c7720615c578d1397c8aa93`로 유지됐다. 기존 사진·메쉬·포즈를 수정하지 않는다. 실제 데이터와 실행 산출물은 Git에서 제외된다.

## 확인과 한계

- Python: 기존 국소 오차 10개, 새 표면 방향·독립 지지·확인 실패 차단 6개, 서버 9개 테스트 통과.
- 앱: 기존 Node 테스트 70개 통과. 브라우저에서 이전 5개의 비교 수치, 청록 표면 표시, 전후 원본 사진 이동, 모바일 폭, 다른 입력 보고서 차단, 기존 영상 2개 유지를 확인했다.
- 실제 사용 대응점의 양쪽 모두가 대상 객체의 전후 경계+여유 영역 밖인지 확인했고, 최종 새 방향의 별도 구역 확인 조건도 모두 통과했다. 기존 이동 설정과 이전 보고서 수치는 유지됐다.
- 전후 기하가 비슷하다는 조건은 안정성의 가설이다. 넓고 일관되게 움직인 주변 물체가 기준으로 섞이거나, 재구성·관측 누락이 크면 분리할 수 없다. 기하만으로 모든 실제 변화와 맵 오차를 구별하는 보장은 없다.
- 오차 범위는 공간 표본·기하 조건에서 구한 경험적 기준이며 보정된 확률·통계적 신뢰구간이 아니다. 방향을 확보했어도 오차가 크면 이동을 확정하지 못한다. 객체 대응 모호성, 사진 투영 오차, 새 방으로의 일반화 성능은 이번 변경으로 해결되지 않는다.
