# spacewatch3d
nudix와 산학연계 협력 프로젝트입니다. by kdj



영상으로부터 카메라의 위치·자세와 장면의 깊이를 추정하여 공통 좌표계의 3D 포인트클라우드 지도를 생성한다. 각 프레임에 2D segmentation을 적용하고, 카메라 자세·깊이·가시성을 이용해 분할 영역의 클래스 정보를 실제로 관측된 3D 점에 연결한다. 여러 프레임에서 관측된 동일 표면의 분류 결과를 통합하여, 각 점에 클래스 정보와 신뢰도, 관측 시각 및 근거 프레임을 연결해 저장한다. 분류가 불확실하거나 정의된 클래스에 속하지 않는 영역은 미확정 또는 기타로 관리한다.
