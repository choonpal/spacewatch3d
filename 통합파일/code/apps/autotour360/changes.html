변화 라벨 읽는 방법

제거 후보는 이전에 있던 변화 표면, 추가 후보는 이후에 나타난 변화 표면입니다. 같은 객체가 이동한 경우에도 이전·이후 위치가 각각 후보로 표시될 수 있습니다.

이동 거리는 동일 객체의 전후 위치가 연결되고 미터 단위가 확인될 때 표시합니다. 현재 데이터에는 객체 대응 정보가 없어 이동 거리를 산정하지 않습니다. 아래 표면 간 거리는 객체 이동 거리가 아닙니다.

데이터 출처와 비교 조건

변화 영역

영역을 누르면 전후 화면이 해당 위치로 이동합니다. 영역 번호는 객체 ID가 아닙니다.

영역을 선택하면 거리와 원본 포인트 근거를 확인할 수 있습니다.
