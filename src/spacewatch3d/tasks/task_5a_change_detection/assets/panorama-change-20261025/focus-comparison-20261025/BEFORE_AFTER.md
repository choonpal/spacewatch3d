# 기존 정합오차·관측검증 / SimSaC 전후 비교

기하 겹침으로 고정했던 44개 사진 쌍을 전(Dorm2)·후(Dorm3)로 나란히 표시한다. 두 촬영은 서로 다른 층이며 시간 변화 정답이 아니다.

기존 판정은 전체 촬영에서 저장된 후보를 각 관측 RGB에 투영한 결과다. SimSaC는 선택한 두 사진의 저장된 양방향 예측을 각각 사용한다. 앞선 다중 상대 평균 결과와 구분하며 새 추론은 실행하지 않았다.

방향 RGB와 ERP 전체 입력 후 방향 투영을 전환할 수 있다. 캐시 확률(float16)을 읽어 0.5 초과를 표시한다. 사람 제외는 두 화면의 대상 프레임 마스크를 각각 사용하고, 원본 후보와 기존 객체 판정은 유지한다.

사람 제외로 달라진 장면은 전·후 중 하나라도 SimSaC 후보가 사람 제외 영역과 겹쳤던 쌍이다. 해당 장면을 선택해도 전후 모두와 두 방식의 객체 후보를 표시한다.

전후 후보 픽셀의 단순 차이를 물리적 추가·소실·이동으로 판정하지 않는다. 원본 RGB·전체 ERP·사람 제외 영역·기존 보류 이유도 전후로 확인할 수 있다.

before-after.json에 쌍별 수치, before-after-validation.json에 입력·캐시 해시와 연결 검증을 보관했다.
