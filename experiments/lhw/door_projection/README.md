# Dorm2 OOOPS 문 투영 실험

2026년 10월 27일에 수행한 CPU 실험이다. SpaceWatch3D v5.1.9가 참조한 Dorm2 v2 메시와 기존 OOOPS B0 점수를 이용해 2D 분류에서 3D 잠정 후보까지의 누락을 추적했다.

## 방법

1. 프레임 00010, 00012, 00015, 00017, 00020의 유효 픽셀과 메시 면 대응을 기존 카메라 자세, 광선 교차, 깊이 검사로 다시 계산했다. 유효 대응 1,778,045개를 사용했고, 5개 프레임 모두 기존 B0 면 라벨을 정확히 재현했다.
2. `door`와 `elevator door`를 상위 문 클래스로 묶었다. 기본 비교안은 두 클래스의 Top-1 합집합이다. support 조건은 유지하고 margin은 문 이외 클래스와 비교했다. 두 문 클래스의 점수 합산은 별도 비교군으로 평가했다.
3. 메시 연결성과 다중 시점에서 일치하는 2D 연결 성분을 이용해 잠정 후보를 생성했다. 엘리베이터 참조를 포함하는 498면 연결 영역은 평면성이 0.758로 기존 기준 0.8에 미달해 통째로 보류됐다. 선택형 `retain_provisional`은 다중 시점 근거가 있는 영역에 잠정 ID와 형상 불확실성을 기록한다.

## 결과

| 조건 | 회색 문 참조 면 | 엘리베이터 문 참조 면 | 전체 잠정 후보 |
| --- | ---: | ---: | ---: |
| 상위 문 Top-1, 비평면 영역 보류 | 206/208 | 0/228 | 7 |
| 상위 문 Top-1, 비평면 영역 잠정 유지 | 206/208 | 226/228 | 8 |
| 상위 문 점수 합산, 비평면 영역 잠정 유지 | 206/208 | 226/228 | 5 |

Top-1 잠정 유지에서 두 문 참조는 각각 하나의 후보에 모였으며 후보 ID는 서로 달랐다. 점수 합산은 문 참조 면을 추가로 확보하지 못했고, 후보에 포함된 기존 벽·바닥 라벨 면은 각각 18·0면에서 118·15면으로 늘었다.

참조 면은 수동으로 선택한 문 내부 픽셀에 대응하는 부분 표면이다. 문 전체 경계, 실제 물체 단위 IoU, 배경 혼입률은 미검증이다. 잠정 ID의 의미는 다중 시점과 기하 근거가 있는 검토용 영역이다.

## 코드와 재현

- `core.py`는 상위 문 점수, 파노라마 경계 연결 및 잠정 후보 계산을 담는다.
- `server_full.py`와 `server_diagnostics.py`는 당시 전체 대응 재생과 단계별 진단 진입점이다. `pipeline.py`의 실험용 헬퍼를 공유한다.
- `compare_cached.py`는 전체 대응 결과에서 비평면 후보 보류와 잠정 유지 결과를 비교하기 위한 캐시 재사용 단계다. 입력은 `full_r1/arrays.npz`, `full_r1/hard_union_relations.json`, `full_r1/metrics.json`이며 결과는 새 `comparison_r3/`에 기록한다.
- 전체 Dorm2 재생에는 당시 서버의 v2 코드, 기존 실행 결과, 대응 인덱스, 메시·카메라 정보와 B0 클래스 점수가 필요하다. 서버 스크립트의 경로는 해당 실행 환경을 기준으로 한다. 캐시 비교에는 NumPy와 Pillow가 필요하다.

당시 캐시가 실험 폴더의 full_r1에 준비되어 있으면 저장소 루트에서 다음 명령으로 비교한다. comparison_r3가 존재하면 새 실험 복사본에서 실행한다.

```sh
python -B experiments/lhw/door_projection/compare_cached.py
```

저장소 루트에서 NumPy와 Pillow가 있는 Python으로 합성 테스트를 실행할 수 있다.

```sh
python -B experiments/lhw/door_projection/test_extended.py
```

원본 합성 테스트 15개가 통과했다. 이 저장소의 테스트는 이전 투표 모듈에 의존하던 한 사례에 고정 투표 결과를 주입해 면 채택 조건을 별도로 검증한다. 업로드본에서도 15개가 통과했다. 실제 Dorm2 표의 수치는 2026년 10월 27일의 CPU 실행 기록이며, 이번 검증은 합성 입력을 사용했다.
