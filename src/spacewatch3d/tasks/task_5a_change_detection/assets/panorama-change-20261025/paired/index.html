후보 수는 SceneDiff 최종 통합 ID 수입니다. 후보 픽셀 IoU는 두 방식이 선택한 영역의 겹침 정도입니다. 후보 경계와 ID 병합 방식이 달라 수가 비슷해도 위치는 다릅니다. 서로 다른 층을 비교한 파일럿이며 시간 변화의 정확도 평가가 아닙니다. 원본 기본 입력 크기는 최대 518입니다.

실험 조건·재현 자료

회차별 16초 기존 인스턴스 결과에서 R01·R07·R08, 각 촬영 5장씩 선택했습니다. 두 경로의 RGB 바이트 해시가 전부 일치합니다. 224×224 공통 입력을 사용했습니다. 원본 로더의 기본 최대 크기는 518이므로 논문 기본 설정의 전체 해상도 재현과는 구분해야 합니다.

두 방식 모두 기하 + 0.1×영역 대응 + 0.5×외형 비용, max-entropy 자동 임계값, 구역별 독립 탐지, 원본의 객체 병합·회차 간 대응을 실행했습니다. 자동 임계값의 수치는 입력별로 달라집니다. 메쉬의 유효 ray hit 신뢰도는 1이며 Pi3의 학습 신뢰도와 다릅니다. 원본의 스케일 정규화·voxel 크기 반환 규칙도 두 경로에 동일 적용했습니다.

빈 영역 처리와 빈 임계값 입력 보호만 공통 적용하고, voxel 평균은 메모리 절약을 위해 같은 평균을 스트리밍 계산했습니다. 기존 인스턴스 ID를 먼저 변화 후보로 지정하지 않았습니다.

Dorm2와 Dorm3는 서로 다른 층입니다. 아래 결과는 공간 차이 후보 비교이며 시간 변화의 정확도·개선율을 뜻하지 않습니다.
