# 원본 360° 전후 비교 · 기존 정합오차 / SimSaC

원본 ERP 20프레임 전체를 2048×1024로 표시하며, 방향 중복을 제외한 구역별 36개 전후 쌍을 사용한다. 224×224 방향 뷰는 cropped-review.html로 보관했다.

저장된 구역 Sim3·이동 편향·원본 카메라 포즈로 같은 3D 지점을 바라보도록 회전을 맞춘다. 카메라 위치는 유지한다. 위치 차이·정합 잔차·가림에 따른 원근 차이는 남는다. 픽셀 단위 영상 정합이나 공통 시점의 새 RGB 생성을 주장하지 않는다.

카메라 간격이 작은 순으로 표시한다. 간격은 맵 단위와 기준높이 대비 비율이며 객체 이동 거리가 아니다. 전체 펼침·드래그·같은 지점 확대·원본 전체 열기를 지원한다. 깊이 표면이 없는 방향은 공통 좌표계 방향으로 연결한다.

SimSaC는 전체 ERP(1024×512) 쌍의 저장된 양방향 캐시를 사용한다. 재추론·재학습은 없다. 원본 확률과 기존 판정은 유지하며 사람 분할·여유를 둔 검출 박스를 두 방법에 동일 적용한다.

Dorm2·Dorm3는 서로 다른 층의 공간 차이 파일럿이다. 관측량이 같은 정확도 평가나 시간 변화 정답이 아니다.
