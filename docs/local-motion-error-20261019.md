# 객체 주변 정합 오차와 이동 비교

현재 변화 투어는 사용자 요청에 따라 기존 이동 9·추가 2·소실 1 분류로 복원했다. 아래는 복원 전 실험 기록이며 현재 화면의 분류·사용법을 뜻하지 않는다. 계산 코드와 산출물은 보존했다.

기존 변화 투어의 객체 대응·전후 사진·사진 조각 겹침을 유지하면서, 이동 항목에 주변 오차 판정을 별도 연결한다. 정답 변화 종류를 새로 맞히는 독립 탐지기가 아니다. 기존 Rescan 객체 대응과 객체별 rigid motion을 입력으로 사용한다.

## 계산

- 이미 정합된 전후 원본 메시와 기존 공통 구조면 추출 결과를 입력으로 사용한다. 원본 메시 SHA256·촬영 회차·좌표 변환을 대조한다.
- 같은 구조면의 전후 표면에서 원본 점 지지 4.5cm 이내, 면 거리 2.5cm 이내, 법선 20도 이내의 표본만 사용한다. 대응은 같은 면의 양방향 최근접 일치와 거리 12cm 이내로 제한한다. 가구 instance/class 라벨을 배경 선택에 사용하지 않는다.
- 대상 객체의 전후 상자와 15cm 여유를 배경 적합에서 제외한다. 전후 객체 위치 주변 1/1.5/2.5m를 순서대로 검사하며, 결과를 원하는 방향으로 바꾸기 위해 반경을 선택하지 않는다. 표본과 방향 제약이 부족한 경우에만 확장한다.
- 주변 표면의 after→before 국소 점-평면 rigid correction을 구한다. 35cm 공간 블록 단위로 가중하고 별도 블록을 확인 구역으로 남긴다. 거의 평행한 법선은 12도 이내에서 같은 방향으로 묶는다. 노이즈로 조금 기울어진 평행 벽을 독립된 세 방향으로 취급하지 않는다.
- 설계 행렬의 영공간으로 객체 위치에서 관측할 수 없는 변위 방향을 구한다. 바닥 하나로 수평 이동을 측정했다고 하지 않는다. 확인 가능한 방향의 보정 후 변위를 별도로 보고한다.
- 블록 내부 절대 잔차 P95의 공간 블록 P95, 확인 구역 잔차, 기하 조건에 의한 증폭, 24회 공간 블록 재표본화를 사용해 경험적 오차 범위를 구한다. mesh 표본 수의 제곱근으로 오차를 줄이지 않는다. 객체 표면 적합 중앙 잔차의 두 배를 보수적인 객체 적합 오차 항으로 더한다. 이는 확률이나 보정된 95% 신뢰구간이 아니다.
- 이동은 확인 가능한 방향의 보정 후 변위가 `max(기존 최소 이동 8cm, 주변 오차 범위+객체 적합 오차)`를 넘는지 비교한다. 회전은 주변의 회전 제약을 모두 관측할 수 있을 때 기존 15도와 주변 각도 오차를 비교한다. 객체 표면 대응률·잔차 조건과 기존 대응 모호성을 함께 보존한다.
- 세 방향을 모두 관측하고 잔여 이동·회전이 오차 이내이면 `정합 오차 범위`, 확인 가능한 방향에서 차이가 기준을 넘으면 `이동/회전 근거`, 그 외는 `판단 보류`다. `정합 오차 범위`도 실제 이동이 절대 없다는 증명은 아니다. 추가·소실은 존재 여부의 기존 분류로 유지하며 이 이동 판정의 대상이라고 하지 않는다.

## 현재 결과와 한계

Rescan scene_e_0/2, 기존 이동 9개 중 이동·회전 근거 4개, 판단 보류 5개, 정합 오차 범위 0개다. 추가 2개·소실 1개는 유지한다. 실제 실행의 최종 수치는 출력 manifest가 기준이다. 주변 구조면이 거의 평행한 벽과 바닥으로 구성되어 많은 위치에서 세 방향 중 두 방향만 확인된다. 두 의자의 기존 대응 모호성도 보류 이유다. 이 결과를 정확도, 실제 이동 정답, 또는 모든 방향의 정합 오차 추정 성공으로 표현하지 않는다.

안정 구조면이라는 가정, 부분 복원, 원본 객체 rigid-fit의 모호성은 남는다. 카메라 자세·RGB 투영 오차를 추정하지 않는다. 국소 보정은 판정을 위한 계산이며, 원본 메시·영상·카메라 좌표를 수정하지 않는다.

## 실행과 연결

```powershell
python tools/build_local_motion_assessment.py --review-dir outputs/rescan-three-changes --structural-dir outputs/structural-reference-rescan-v5-20261016 --output outputs/local-motion-assessment-20261019/run-v3
python apps/autotour360/server.py --port 8768 --rescan-dir outputs/rescan-three-changes --motion-assessment outputs/local-motion-assessment-20261019/run-v3/motion-assessment.json
```

출력 폴더는 비어 있어야 한다. 결과는 원본 changes.json과 별도이며, 공개용 `motion-assessment.json`과 비공개 대응점·구역 추적 파일을 나눈다. 브라우저는 원본 manifest의 SHA256, 메쉬 해시, 회차, 정합 행렬을 검사한다. 분석이 없거나 다른 촬영의 결과이면 이동을 판단 보류로 표시한다. 기존 사진 연결과 원본 객체 사진 겹침은 유지된다.
