기존 후보는 무엇이었나

입력 조건과 결과 해석

기존 자동 판정은 occupancy-evidence-v2의 반복 관측·구역별 정합오차·반대 촬영의 독립 비점유 관측을 사용했습니다. 이 페이지에서는 그 판정을 다시 계산하거나 임계값을 조정하지 않았습니다. 후보 그룹 전체의 의자 메쉬를 변화 영역으로 칠하지 않고, 실제 후보를 만든 트랙의 원본 면만 주황색으로 표시합니다.

SimSaC·ViewDelta는 공개 학습 가중치가 전량 로드된 기존 추론 결과입니다. 상대 선택은 기존 SceneDiff의 메쉬 view-overlap으로 고정했으며 변화 점수로 상대를 고르지 않았습니다. 모든 비영 상대의 확률을 평균한 뒤 0.5 초과를 표시합니다. 두 모델의 동일 입력 자기 비교는 후보 0픽셀이었습니다.

기본적으로 대상 RGB 프레임의 기존 YOLO11l 사람 분할·검출 박스 합집합과 겹치는 모델 후보를 제외합니다. 외곽·옷의 누락을 줄이기 위해 박스 안의 주변 표면도 보수적으로 제외합니다. RGB 사람 뒤로 투영된 기존 메쉬 표면도 비교에서 제외합니다. ‘사람 제외’를 끄면 필터 전 원본으로 돌아갑니다. 확률·임계값·기존 객체 판정은 유지하며, 반대 촬영 사람의 영향까지 모두 제거됐다는 뜻은 아닙니다. 30뷰의 중복 관측 픽셀을 물리적 객체 수로 세지 않습니다.
