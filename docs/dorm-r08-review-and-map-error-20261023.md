# R08 사진별 검토와 R05 주변 구조 오차 진단

## 구역 5의 같은 창문이 잡힌 원인

P0012는 면적 변화량으로 뽑힌 것이 아니다. 메시 간 거리 중앙값 0.1710 u가 구역 기준 0.1439 u를 넘고 공간 일관성·카메라 조건을 통과했기 때문이다. 면적은 작은 조각을 거르는 최소 크기 조건이다.

원본에서 창문은 비슷하게 보인다. 창면을 맞추는 대신, 두 촬영의 **창틀·벽 테두리**에서 각각 평면을 추정했다. 같은 x/y 위치에서 그 기준면이 약 0.1387 u 어긋나 있다. 이 테두리 차이에 따른 국소 이동만 적용해 창면을 다시 비교하면 양방향 표면 거리 중앙값은 **0.1711 → 0.0394 u**로 줄고 0.1439 u 기준 아래로 내려간다.

이는 객체 이동보다는 주변 구조까지 포함한 국소 정합·재구성 오차가 주원인이라는 근거다. 이 계산은 진단용이며 원래 맵이나 객체에 새 정합을 적용하지 않았다. 테두리 평면의 차이에도 재구성·카메라 오차가 들어갈 수 있으므로, 전체 오차 중 몇 퍼센트가 순수 정합인지 완전히 분해했다고 주장하지 않는다. 객체 표면을 피팅한 뒤 이동을 지운 실험도 아니다.

P0012와 같은 창의 P0019는 재질 제외 후 후보에서 빠졌다. 구역 5의 다른 문·벽 경계·천장 모서리 후보까지 실제 객체 변화가 입증된 것은 아니다.

## 벽·유리 제외

- 공통 큰 수직 평면은 두 메시에서 독립적으로 찾고 방 부근의 평면 간격·방향·범위로 대응한다. 월드 원점에서의 평면 절편 차이만 비교하지 않는다. R12처럼 원점에서 멀 때 작은 법선 차이를 큰 이동으로 오해하는 문제를 막는다.
- 공통 벽면 자체의 삼각형은 제외한다. 벽 가까이 있는 낮은 가구에는 좁은 평면 두께를 적용하고, 높은 벽면의 완만한 복원 편차에는 해당 구역 오차를 반영한다. 객체 분할 ID는 쓰지 않는다.
- 유리/반사성 면은 일반 메시 기하만으로 확실히 알아낼 수 없어 **원본 사진에서 사람이 지정한 재질 영역**을 사용했다. `docs/dorm-material-exclusions-20261023.json`의 R05/R12 각 촬영 창 면 총 4개다. 창틀 바깥 테두리의 실제 메시로 평면을 구하고 그 면 또는 뒤쪽을 제외한다. 창 앞에 있는 가구는 유지한다. 이는 자동 유리 인식 모델이나 instance segmentation 결과가 아니다.
- 원본 전체 맵을 삭제하거나 고치지 않고 판단용 삼각형 마스크만 적용한다. 예전 ID는 원래 삼각형 겹침으로 유지하며 예전 후보의 판정값을 새 탐지 조건으로 쓰지 않는다.

최종 `run-v10/published`는 **변화 의심 21 / 판단 보류 19 / 제외 10구역**이다. R08의 8개는 유지된다. R12의 벽 P0036은 후보에서 빠졌지만 남은 19개 삼각형이 완전히 설명된 것은 아니므로 보류 내역에 남긴다. 이것까지 자동으로 반사라고 확정하지 않는다.

## 화면과 실행

기존 Auto Tour의 `R08 8개 사진 비교 · 맵 오차 설명` 버튼은 같은 화면 안의 대화상자에 8개 전후 원본·위치 박스·거리·정합 기준·사진 해석을 보여준다. `맵·원본 상세 보기`를 누르면 해당 영역을 지도에서 확인한다. `?source=dorm&mode=changes&review=r08`로 바로 열거나 `&patch=P0012`처럼 개별 ID로 들어갈 수 있다. 벽·유리 제외 내역은 원본을 보존한 채 따로 확인한다.

```powershell
python tools/build_dorm_surface_changes.py --source D:/ChatGPT/Workspaces/Projects/jonghap_project/outputs/registration-benchmark-20261019/new-meshfirst-20261022 --output outputs/dorm-surface-change-20261023/run-v9/published --materials docs/dorm-material-exclusions-20261023.json --previous outputs/dorm-surface-change-20261023/run-v3/published

```

기존 출력 폴더를 재사용하지 말고 새 실행 경로를 지정한다. `--previous`는 표시 ID 유지에만, 사진 검토 JSON은 설명에만 쓰인다. 기본 서버는 run-v10을 읽는다. 계산 테스트 8개(월드 원점 불변성·유리 앞 표면 보존·벽 앞 가구 보존 포함), 프런트엔드 분류 테스트 4개, HTTP 테스트 11개를 통과했다. 실제 브라우저에서 사진 비교 대화상자의 8개 항목과 오차 진단 문구를 확인했다. 정답 대비 탐지 성능 평가를 수행했다는 뜻은 아니다.
