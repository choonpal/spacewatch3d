# 테스트 위치

`test_contracts.py`는 task 경계의 ID·좌표 메타데이터·프레임 출처·파일 경로를 검사합니다.
각 task 담당자는 `tests/task_번호_이름/`에 실제 로직을 검증하는 테스트를 추가합니다.
`unittest discover`가 하위 디렉터리를 탐색하도록 해당 테스트 디렉터리에 `__init__.py`를 추가합니다.

무거운 GPU 추론 검사는 기본 공통 suite에 넣지 않습니다. 별도 실행 명령과 필요한 데이터를 task README에 기록합니다.
CI에 없는 모델 성능 검증을 완료한 것으로 보고하지 않습니다.
