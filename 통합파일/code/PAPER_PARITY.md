## 이번 통합에서 바로잡은 연결 오류

- 원래 변화 스냅샷의 객체 확대 우선순위는 고정 표였다. 정수기 3/표지판 3은 실제 LLM 평균 4/2와 다르고, 조명은 표에서 빠졌다.
  논문에 맞춰 현재 검증된 14종 LLM 점수와 확대 후보 자격을 연결했다. 원래 입력 파일을 수정하지 않고 새 manifest에 넣는다.
- 19종 입력에서 사람 ID는 15, 우산은 16이다. 원래 사람 전처리의 고정 번호 비교 2곳만 클래스명에서 구한 번호로 연결한다.
  원본 코드와 변환 소스 해시, 변경 위치를 남기며 우산을 사람으로 지우지 않는다.
- 원래 코어가 지원하지 않는 비활성 설정 키를 덧붙이지 않고, 실제 프로필의 Config로 실행 전 검사한다.
- 품질 검사에 PyAV가 설치된 원래 환경을 연결한다. 라이브러리 신규 설치나 품질 설정 축소는 없다.
- 실제 연결 시험에서 모델의 원본 ERP 상대경로가 다음 단계의 작업 폴더에서 깨지는 오류를 고쳤다.
  준비된 845개 영상의 촬영·프레임·원본 사진 60장의 해시를 검증해 추론 전용 복제 manifest에 절대경로를 연결한다.
  원래 영상·배열·정합·선정은 수정하지 않으며 완료 단계는 해시를 확인해 재사용한다.
- 모델 추론과 객체 대응 특징 추출을 같은 프로세스에서 연달아 수행하던 것을 분리했다.
  원래 두 계산 함수·가중치·입력·문턱은 그대로이며, 한 작업이 종료해 메모리를 반환한 뒤 다음 작업을 시작한다.
  실제 1,282쌍 추론 완료 결과를 해시 검증한 체크포인트로 보존하고 중단된 객체 대응 부분만 별도 프로세스로 복구했다.
  이 계산을 새 시도에서 통째로 다시 수행했다고 표시하지 않으며, 재사용·복구 출처와 시간을 구분한다.

## 실제 확인과 미확인 구분

- 새 연결 실행 `execution06/run`은 분류·검증·게시·뷰어까지 완료했다. Dorm4는 543후보에서 15개,
  Dorm5는 554후보에서 10개가 선정됐고 97개 HTTP 자산 검사에서 오류가 없었다.
  새 변화 결과는 원본 후보 5개·규칙 기반 묶음 2개이며, 원본 후보 5개는 모두 `unresolved`이다.
  파일명의 `verified_changes`는 원래 코드의 묶음 명칭이지 독립 정답 검증을 의미하지 않는다.
- **최종 선정과 별도 효과 평가를 구분한다.** 논문의 최종 Dorm5 혼합 선정은 10개이며
  현재 통합본도 그 10개를 사용한다. 이전 15지점 주변 입력의 변화 효과 평가와 현재
  10지점 주변 입력의 통합 실행은 같은 실험이 아니다. 과거 6후보·3묶음과 현재
  5후보·2묶음의 차이만으로 논문 방식의 구현 불일치를 판정하지 않는다. 현재 상자 근거
  두 원본 중 한 장이 주변 범위 밖으로 빠져 반복 관측 조건을 넘지 못한 것은 결과의
  한계로 기록한다. 옛 검출이나 알려진 프레임을 넣어 평가 개수를 맞추지 않았다.
- 전체 영상 선명도, 후보, 새 V/Q, 선정, 실제 ERP 추출, 새 정합을 실행했다. 선정 이후의 원래 검증 단계가 선정 집합을 바꾸지 않는 것도 검사했다.
- Dorm5 혼합 조건의 10개 ID·순서·두 점수는 채택된 원래 `totalstop03` 결과와 정확히 일치한다.
  논문의 모사 장면에서 객체 정보를 지운 실험 결과와 실제 Dorm5 점수를 섞지 않는다.
- 같은 고정 관측 행렬에서 공간만 8개, 객체만 11개도 다시 확인했다. 객체 조건은 순서·점수까지
  일치한다. 공간 조건은 예전 결과가 이미 교체한 집합을 다시 시작점으로 받아 추가 교체했으므로,
  저장된 시작 집합을 가져오지 않는 현재 실행과 위치·점수가 약간 다르다. 정확히 같은 그림이라고 하지 않는다.
- 수정 영향이 없는 완료 단계는 코드·입력·산출물 해시와 의존 토큰 검사 후 명시적으로 재사용한다.
  원래 계산 시간과 이번 재사용 시간을 따로 기록한다. 옛 최종 검출 결과를 새 검출로 가져오지 않는다.
- 현재 가용 RAM이 원래 복원부터 다시 실행할 안전 기준(16GiB)보다 작아 전체 cold 실행은 아직 미확인이다.
  원래 생성기는 통합 진입점에 연결했으며, 계약 시험·입력 점검·검증된 재사용 실행은 완료했다. 이것을 새 전체 모델 추론 성공이라고 표현하지 않는다.
- 보간 자세, 물리 축척, 모든 객체 관측 충족, 변화의 독립 정답 정확도는 자동 보증하지 않는다.
  원래 `targets_unmet`·`UNVERIFIED` 상태를 유지한다.
- 중요도는 기존 동일 매뉴얼의 5회 응답 캐시를 사용한다. 보존된 요청 ID
  `gemini-3.1-flash-lite`와 논문의 축약 명칭만으로 통합 과정의 모델 교체를 주장하지 않는다.
  당시 제공자의 실제 반환 모델 버전은 저장되지 않았다.
- 실제 준비 영상 845개 모두 `capturer_only`이고 일반 사람의 의미 라벨은 유지된다.
  RGB-person 분기에서 사람 후보 EV-005도 생성됐다. 최대 3개 객체 확대 목록의 사람 제외는
  원래 채택한 코드와 동일하다. 이 제한을 일반 사람 전체를 제거하거나 탐지를 누락한 것으로
  해석하지 않는다. 사람 변화 분기 소스는 채택된 원본과 바이트 단위로 같다.

배포 범위는 `RELEASE.json`, 실제 계산 상태는 `evidence/calculation_status.json`,
출처와 최종 배포 시험은 `evidence/`를 따른다. 최종 프로그램 배포와 논문 수치의 완전 재현은 구분한다.
