전 = Dorm2 · 후 = Dorm3. 서로 다른 층의 공간 차이 파일럿입니다. 기존 방식은 저장된 전체 촬영 판정, SimSaC는 선택한 전후 사진 쌍의 예측을 표시합니다.

전후 객체 후보의 차이

전후의 시점·가림·분할 범위가 달라 픽셀 면적 차이를 곧바로 추가·소실·이동으로 확정하지 않습니다. 사람에 가려진 메쉬 투영도 같은 제외 영역으로 처리합니다.

기존 객체 판정과 SimSaC 원본 확률은 유지합니다. SimSaC는 선택한 두 사진을 양방향으로 비교한 저장 예측을 사용하며 평균 확률을 다른 상대 사진과 혼합하지 않습니다. 후보 기준은 0.5 초과입니다. 사람 제외를 끄면 필터 전 후보를 볼 수 있습니다. 사람 필터는 대상 RGB 좌표의 후처리입니다.

기존 방식은 전체 촬영의 반복 관측·정합오차·독립 비점유 근거를 사용했습니다. 두 방식의 관측량이 같지 않고 변화 정답이 없어 현재 화면은 정확도 순위가 아닙니다.
