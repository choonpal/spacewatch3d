# Task5b 개선 작업 메모

객체별 3D 메시와 메타데이터에서 중앙 경로와 360도 키프레임 위치를 선정한다. 서버가 3D 맵을 처리하고, 사용자에게는 선정 위치의 파노라마를 제공한다. 실제 이미지 합성은 별도 파트다.

## 유지할 결정

- 벽과 천장은 `structures`로 전달하고 공간 커버리지로만 평가한다. `objects`의 wall과 ceiling 등 명시적 이름도 구조물로 처리한다. 객체 중요도나 LLM 점수를 추가하지 않는다.
- 환풍구 등은 별도 객체 ID와 메시가 있어야 객체 중요도를 적용한다. 가시성은 높이와 가림을 포함한 3D 계산이며, 평면도는 표시 방식일 뿐이다.
- 중앙 경로는 확인된 단일 수평 바닥에서 만든다. 카메라 높이는 건물 크기에 비례시키지 않고 촬영 조건을 따른다.
- LLM은 중요도 제공자만 추후 연결한다. 지금은 수동 점수와 기본값을 유지한다.
- Task5b와 전용 테스트만 수정한다. 공통 계약과 다른 task는 변경하지 않는다. GitHub 커밋과 업로드는 별도 명시 요청 없이는 하지 않는다.

## 작업 순서

1. [x] 적응형 후보 배치: 분기와 좁은 구간을 보강하고, 인접 후보의 가시성 변화가 큰 구간을 한 번 더 탐색한다. 보강 간격은 격자 해상도 이상이고 분기와 끝점은 보존한다. `candidate_report`에 원인을 기록한다.
2. [x] 촬영 높이 입력: 명시 설정, `camera.height_above_floor_m`, 경고를 남기는 임시 1.5m 순으로 적용하고 출처를 기록한다. 건물 크기에 비례시키지 않는다.
3. [x] 전체 이미지 수 고려: 이동용 이미지까지 포함한 추가 정보량과 추가 장수로 선정한다. 목표를 보존하는 제거와 단일 교환을 적용하며 전역 최소 장수를 보장하지 않는다.
4. [x] 회귀 검증: 천장과 높은 객체의 가림, 구조물의 의미 점수 제외, 적응형 후보, 높이 우선순위, 이동용 장수와 필수 객체 조건을 시험한다. 밀도와 선정 비교는 같은 표면 표본과 공통 분모를 사용한다.
5. [ ] 후속: 정보 손실을 검사하는 가지 정리와 충돌 재검사 기반 평활화, 실제 맵과 같은 장수 비교 실험, 합성 가능 후보 제한, 회차 간 기준 경로 재사용.

## 완료 판단과 주의사항

- 후보를 늘린 후 관측 가능한 표면 분모를 고정하고 선정한다. 관측 가능 표면 기준과 입력 전체 표면 기준 커버리지를 모두 기록한다.
- 벽을 관통하는 연결, 분리 공간 순간 이동, 필수 객체 누락을 성공으로 처리하지 않는다.
- 후보 밀도와 표면 샘플 수 모두 근사 정확도에 영향을 준다. 합성 맵 통과를 실제 이미지 품질 검증으로 표현하지 않는다.
- 합성 가능 범위는 렌더러 파트의 입력이 필요하다. LLM 연결과 자동 정합, 실제 이미지 합성은 이번 수정에서 구현하지 않는다.

## 현재 상태

- 기존 기준 예시: 후보 35개, 핵심 3개와 이동용 6개, 총 9개 이미지 위치. 실제 이미지는 없음.
- 개선 예시: 후보 123개. 기본 구역 균형 공간 목표 90%에서는 위치 2개, 관측 가능 표면 90.56%; 목표를 전체 균형과 구역별 99%로 올리면 위치 7개, 관측 가능 표면 99.38%. 이전 9개 위치의 99.42%와 구별한다. 두 개선 실행 모두 관측 가능한 객체 중요도 조건과 필수 객체 조건을 만족했다.
- 비교 도구: `examples/compare_planning.py`. 모든 경로 노드와 동일 표면 샘플 600개를 공통 기준으로 삼았다. 밀도와 선정 방식의 비교이며 같은 장수 비교나 실제 이미지 품질 검증은 아니다.
- 검증: 전용 53개와 공통 19개, 총 72개 테스트. 실제 촬영 데이터와 이미지 품질은 아직 미검증이다.
- 기존 OBJ와 GLB 합성 맵 4개도 재검증했다. 연결된 3개는 완료, 분리 공간 1개는 `disconnected_tour` 미완료였다. 입력 파일은 보존됐고 중앙선 그래프는 이전의 독립 충돌 검사 결과와 동일했다.
- 계산 비용: 이 작은 예시에서 기존 약 1.8초, 개선 약 6.4초였다. 후보 증가로 서버 계산은 늘며 이미지 수 감소와 별개다. 처리 시간은 실행 환경에 의존한다.
- 다음 작업: 항목 5. 가지를 짧다는 이유만으로 제거하지 말고, 가시성이나 필수 객체 손실을 검사한 뒤 적용한다. 외부 렌더러 관측 범위와 실제 팀 맵이 필요한 작업은 입력 계약부터 확인한다.
