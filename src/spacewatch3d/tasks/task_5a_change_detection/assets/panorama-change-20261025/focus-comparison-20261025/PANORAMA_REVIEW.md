# 360° 전 영상 후보 둘러보기

처음에는 전 360° 영상 하나만 표시한다. 기본 목록은 사람 제외 후 선택한 방식의 후보가 남은 쌍이다. 전체 쌍·사람 제외 비교 모드에서는 후보 0인 쌍도 확인할 수 있으며 전/후 후보 수를 목록에 표시한다. R01 전 133 ↔ 후 142의 SimSaC는 원본 전 0·후 156픽셀이며 후 156픽셀이 모두 사람 영역으로 제외된다.

기존 정합오차·관측검증과 SimSaC만 선택한다. 전·후 양쪽 후보를 전 영상 좌표에 표시한다. 후에서만 검출된 후보는 후의 첫 메쉬 깊이와 저장 포즈로 전 시점에 투영한다. 깊이가 없는 후 후보는 방향만 맞추는 근사 위치이며 개수를 기록한다. 사람 제외 시 후 원본 사람 영역과 투영 위치의 전 사람 영역을 제외한다.

바운딩박스는 1024×512 ERP의 후보 연결 영역을 3픽셀 여유로 묶는다. 원본 후보를 새로 만들거나 확률을 바꾸지 않는다. 보존된 각 원본 후보 픽셀이 정확히 한 박스에 포함되는지 검사한다. 박스는 semantic instance나 확정 객체 변화가 아니며 내부의 모든 픽셀이 변화 후보라는 뜻도 아니다.

박스를 누르면 해당 박스 안에서만 후 RGB를 55% 겹쳐 표시한다. 전만 보기·반투명 겹침·선택 영역 후만 및 0–100% 슬라이더로 비교한다. 전 메쉬의 첫 표면 깊이와 저장된 구역 Sim3·카메라 포즈로 원본 후 RGB를 샘플링한다. 전 깊이가 없는 곳은 투명하다. 관측 RGB를 재투영할 뿐 새로운 내용을 생성하지 않는다. 촬영 위치·가림·메쉬·정합 잔차는 남으며 반투명 경계 차이가 객체 이동의 증거는 아니다.

원본 ERP 20프레임 전체에서 36쌍을 사용한다. 둘러보기 모드가 기본이고 드래그·방향키·확대·전체 화면을 지원한다. SimSaC는 전체 ERP 쌍의 저장된 양방향 추론이며 새 추론·재학습은 없다. 원본 예측·판정·메쉬를 바꾸지 않는다. 이전 224px 방향 뷰는 cropped-review.html에 보관했다.

Dorm2·Dorm3는 서로 다른 층의 공간 차이 파일럿이다. 정확도 순위나 시간 변화 정답을 제시하지 않는다. panorama-interactions.json과 interaction-validation.json에 박스·근사 투영·입력 해시를 기록한다.
