SpaceWatch v5.1.9 — 공통20cm 키포인트 생성 기준

현재 릴리즈 v5.1.9: 모든 새 키포인트 생성의 기본 clearance_m=0.20 m. 기존 Dorm3 결과는 보존한다.
검증 결과와 제한 사항: docs/KEYPOINTS_5_1_9.txt. 과거 검증 수치는 아래에 별도로 보존한다.

일반 v4 기반 + 입력별 관측 대상 정책 + 키프레임 + 실제 3DGS + 뷰어.
기본 입력은 기존 dorm2·dorm3 라벨 메시입니다. Dorm2는 크기 기준87개, Dorm3는 통계 필터93개 관측 대상입니다.
설정된 GPU 서버의 데이터와 Python 환경을 사용합니다. ZIP만으로 다른 PC에서 모델 추론이 되지는 않습니다.

1. 서버에서 시작 / 이어 실행
   ssh -p 4444 root@155.230.28.172
   cd /workspace/spacewatch_pipeline_v5_1
   ./start_v5_1.sh

   SSH 창을 닫아도 실행은 계속됩니다. 완료된 단계는 검증 후 재사용합니다.
   같은 출력에 완료 결과가 있으면 그 결과를 재사용하고 뷰어를 연결합니다.
   새로 계산하려면:
   ./start_v5_1.sh configs/dorm2_dorm3.json /workspace/spacewatch_runs/my_v51_run

2. 진행 상태
   ./run.sh status --output /workspace/spacewatch_runs/dorm2_dorm3_pipeline_v5_1_9_20261027
   tail -f /workspace/spacewatch_runs/dorm2_dorm3_pipeline_v5_1_9_20261027/launch.log

   실행 중지:
   ./run.sh stop --output /workspace/spacewatch_runs/dorm2_dorm3_pipeline_v5_1_9_20261027
   재개: ./start_v5_1.sh

3. PC에서 결과 보기 (압축을 푼 폴더에서)
   python3 connect_viewer.py
   기본 브라우저 주소: http://127.0.0.1:18786/pipeline.html
   이 포트가 사용 중이면 빈 포트로 연결하며 실제 주소를 출력하고 브라우저를 엽니다.
   SSH 인증을 요청하면 터미널에서 인증합니다. 터널 종료 후에는 이 명령으로 다시 연결합니다.
   다른 실행은 --run /workspace/spacewatch_runs/my_v51_run 으로 선택합니다.
   상단의 변화 비교 열기 버튼: 전후 메시 나란히 보기, 구역 선택, 동기 회전/확대, 판단 근거 확인.
   직접 주소: 출력된 주소의 pipeline.html을 pipeline-changes.html로 바꿉니다.

4. 설정 변경
   configs/dorm_size_assumptions.json: 종류별 크기 가정, 허용 오차, 최소 지지.
   configs/dorm2_dorm3.json: 입력 경로, 계획 설정, 런타임.
   크기 불일치·작은 조각·미분류 면은 삭제하지 않습니다.
   Dorm2는 기존 개별 필수 조건을 유지합니다. Dorm3는 전체 개별 필수를 해제하고 개수 목표90%를 사용합니다.
   코드/설정/입력을 바꾸면 새 출력 폴더를 사용합니다.

5. 결과 해석
   실행 complete는 파이프라인 처리 완료입니다.
   계획 incomplete는 일부 객체 관측 또는 경로 연결 목표가 남았다는 뜻입니다.
   docs/V5_1_VALIDATION.txt에 실제 실행 결과와 검증 범위가 있습니다.
   자세한 설정·새 입력·오프라인 내보내기: README.txt.


5.1.8 Dorm3 키프레임 업데이트
Dorm3 기본은 통계 필터93개 대상 + 캐시된 클래스 중요도 + 평지 경로 보정 + 상한 해제된 선정기이며 require_all_objects=false다.
이번 고정 입력 재선정은13개였다.13개를 강제하지 않는다. 입력이 바뀌면 프로필 재사용을 거부한다.
선정 완료와 전체입력 목표 충족은 다르다.83/93품질충족,전체입력90%및기존지역별목표는미달이다.
Dorm2 크기 방식과5a변화탐지는 그대로다. Dorm3에서 크기 템플릿으로 관측 대상을 다시 만들지 않는다.
문서: docs/DORM3_PROFILE_5_1_8.txt. 복구: 서버 배포 영수증의 backup 경로. 새 출력 폴더로 실행한다.

검증 완료: Dorm3 통합 재실행에서 동일13개 시점·경로 재현, 실제3DGS 파노라마13장 생성, 검증 및 뷰어 연결 통과.
PC에서 이번 결과 연결: python3 connect_dorm3_viewer.py
선정 complete와 전체입력 목표 미달(83/93)을 구분한다.
