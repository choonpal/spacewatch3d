# SpaceWatch3D 실험 검증 목록

이 문서는 이전 SpaceWatch3D 스냅샷에서 수행한 실험과 검증 범위를 기록합니다. 아래 수치는 당시 저장된 실행 결과입니다.

| 실험 | 검증 내용 | 기록된 결과 |
| --- | --- | --- |
| Dorm2 점군 정제 및 크기 기준 | 동일한 원본 3D 관측으로 기존 방식과 개선 방식 비교 | 관측 102개의 입력 좌표 해시 일치. 보존 관측 96 → 102개, 크기 기준 채택 후보 1 → 2개. 최종 ID 5개 유지, ID 할당 면 1,227 → 1,320개. |
| Dorm2 OOOPS 문 투영 | 저장된 결과로 5개 프레임의 2D→3D 대응 재생 및 상위 문 영역 비교 | 기존 B0의 프레임별 면 라벨 정확히 재현. 회색 문 참조 206/208면과 엘리베이터 문 참조 226/228면이 서로 다른 잠정 후보에 배정됨. 합성 테스트 15개 통과. |
| Dorm2 의자 후보 회귀 | 연결 영역과 크기 판정으로 인한 후보 소실 분석 | 기존 후보 14개의 1,260면 중 1,247면이 새 잠정 후보에 포함됨. 전체 메시 147,020면 보존. 신규 테스트 12개 통과. |
| Dorm4·Dorm5 키프레임 기여도 | 각 선택 지점의 단독 제거가 공간 및 객체 관측률에 미치는 영향 비교 | 단독 제거 40건. 기존 표면 관측률을 10개 입력·표본 조합에서 오차 10⁻⁸ 미만으로 재현. 기존 품질 여유까지 유지한 단독 제거 사례는 0건. |

문 참조 면은 문 내부 ROI에 대응한 면입니다. 물리적 객체 경계, 실측 크기 정확도, 현재 main에서의 재현 여부는 별도 검증이 필요합니다.
